Workflow

  1. Press CtrlP and type a property path.
  2. Set global maps to Yes, then lookup on cs2kz.org to autofill.
  3. Only changed fields are saved. Press Export Changes to download them.
  4. In the dev workspace, run npm run apply:changes -- maps_changes.json.

Deltas save automatically to this browser's local storage (cookies are limited to ~4 KB). Export regularly — clearing site data removes them.

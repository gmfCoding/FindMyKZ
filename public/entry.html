Workflow

  1. Press CtrlP and type a property path.
  2. Set global maps to Yes, then lookup on cs2kz.org to autofill.
  3. Only changed fields are sent to the API (POST/PUT) and stored in SQLite.
  4. History shows the private audit trail: every change as old → new.

Start the backend with npm start. Without it, changes stay in this browser and can be exported as a delta file.
